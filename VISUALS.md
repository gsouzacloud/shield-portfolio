# Imagens do portfólio

`overview.png` é uma composição demonstrativa preparada para explicar as funcionalidades do projeto. Não é uma captura de uma sessão real. Todos os números, entidades e estados apresentados são fictícios. Não contém dados, hostnames ou endereços de clientes.

A imagem não comprova desempenho, cobertura de produção ou resultado comercial. As capacidades existentes e propostas estão distinguidas no README e no roadmap.
